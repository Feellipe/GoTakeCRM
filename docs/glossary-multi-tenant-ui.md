# Glossary — Multi-Tenant UI

| Term | Definition |
|------|-----------|
| **My Work** | Personal workspace of a user. Always exists. Contains solo projects, personal client roster, and personal configuration (WhatsApp). |
| **Organization** | A shared workspace (agency, studio) with multiple members. Has its own clients, deals, proposals, and configuration. |
| **All Work** | Consolidated view showing data from My Work + ALL organizations the user belongs to. |
| **Active Context** | The currently selected view in the sidebar — either "All Work", "My Work", or a specific org. |
| **Autônomo** | Org role. Can see and work on assigned clients/deals only. Cannot access org settings. |
| **Admin** | Org role. Full access to org data + settings (members, Stripe). |
| **CRM** | Org role. Can see clients, conversations, proposals (read/edit). Cannot see financials or settings. |
