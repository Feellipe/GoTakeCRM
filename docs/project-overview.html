Pricing Model Change

Effective July 1, 2025, Meta switched from conversation-based pricing to per-message pricing. You are now charged per delivered template message only. Non-template messages (text, images, video, interactive lists) are always free.

11. Key Architectural Decisions

  1. No middleware — auth checked per-route, not at the edge. Every API handler repeats getServerSession → user org check.
  2. No Server Components — every page is 'use client'. Dashboard layout fetches via SWR, provides data through React Context.
  3. Multi-tenant aggregation — dashboard API supports ?orgId= for single-org view, otherwise aggregates across all user's orgs.
  4. Stripe per-org — each organization stores its own Stripe keys; checkout and webhook use per-org credentials.
  5. WhatsApp session state — CommandSession model with TTL expiry, checked on every incoming message.
  6. TypeScript ignoreBuildErrors: true — build passes even with TS errors (pragmatic for rapid iteration).
  7. Child-model isolation — Expense, Revenue, Briefing have no organizationId; tenant isolation enforced through the Deal → Organization chain.
  8. Vercel São Paulo — deployed to gru1 region for low latency in Brazil.
  9. Webpack build — --webpack flag in vercel.json (not Turbopack).
  10. PWA via Serwist — cache-on-navigation, installable, offline-ready.
